# 📰 Random News Headline Generator

![Python](https://img.shields.io/badge/Python-3.x-blue)
![Beginner Friendly](https://img.shields.io/badge/Level-Beginner-brightgreen)
![CLI App](https://img.shields.io/badge/Type-CLI%20Application-orange)
![License](https://img.shields.io/badge/License-MIT-lightgrey)

A beginner-friendly **Python CLI application** that generates random news headlines using predefined subjects, actions, places, and emojis.

This project helps beginners practice:
- Python basics
- Randomization
- Functions
- Lists & dictionaries
- File handling
- User input handling

---

## ✨ Features

- Generates random news headlines
- Multiple categories available
- Emoji-enhanced output
- Option to save headlines to a file
- Simple and clean command-line interface

---

## 🗂 Categories Available

1. Funny News 😂  
2. Political News 🏛️  
3. Celebrity News 🌟  
4. Animal News 🐾  

Each headline is randomly generated using:
- Subject  
- Action  
- Place  
- Emoji

## ▶️ How to Run the Project

### Step 1: Clone the repository
```bash
git clone https://github.com/YOUR_USERNAME/random-news-headline-generator.git
```

### Step 2: Navigate into the project folder
```bash
cd random-news-headline-generator
```

### Step 3: Install requirements
```bash
pip install -r requirements.txt
```

### Step 4: Run the program
```bash
python main.py
```

---

## 💾 Saving Headlines

- After generating a headline, the program asks whether you want to save it.
- Saved headlines are stored in:
```
headlines.txt
```
- Each saved headline includes a timestamp.
